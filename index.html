Privacidad

Tus datos de salud, solo tuyos.

MedBox no pide registro y no usa servidores propios para guardar tu botiquín: todo se queda en tu dispositivo. Las únicas conexiones a internet que hace la app son, si tú lo pides, consultar el nombre y el prospecto de un medicamento en la base de datos pública y oficial de CIMA (AEMPS), y el envío de estadísticas de uso anónimas para mejorar la app.

  • ✅ Todo el inventario se guarda en tu dispositivo
  • ✅ No se requiere cuenta ni email
  • ✅ Sin anuncios ni venta de datos a terceros
  • ✅ Código abierto — puedes revisarlo tú mismo

Preguntas frecuentes

¿Tienes dudas?

¿Necesito internet para usar la app?

No. El inventario funciona completamente offline. Solo hace falta conexión si quieres autocompletar un medicamento por su C.N. o descargar su prospecto.

¿Qué es el C.N.?

El Código Nacional es el número que identifica a cada medicamento en España, impreso en la caja. Con él, la app busca el nombre y la presentación en CIMA, la base de datos pública de la AEMPS.

¿Puedo usarla para toda la familia?

Sí, puedes registrar todos los medicamentos del botiquín de casa en un mismo inventario.

¿Para qué plataformas está disponible?

MedBox ya está disponible tanto para Android como para iOS.
